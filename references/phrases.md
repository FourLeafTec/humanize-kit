# 高频 AI 词汇参考（phrases）

> 用途：改写/审阅时对照的词汇表。**不是禁用词黑名单**——每个词都给出「何时保留」，单次出现且语境自然的不算问题，成簇、连段出现才处理（弱单独项尤其如此）。分类编号对应统一模式分类法（A–F，31 项）。

## 元信息

| 项 | 内容 |
|---|---|
| 语言 | 中文优先，中英双语 |
| 覆盖分类 | C12 空泛高频词、C13 意义拔高、C15 句尾拔高、C16 宣传语、C17 权威背书、E22 客服腔、E23 免责与猜测填充、F27「进行+动词」、F30 万能背景、F31 套话收尾，以及 A4 起跑式铺垫、B9 限定堆叠 |
| 使用原则 | 先判断含义与文体，再决定是否修改；正式语体、工程术语、用户惯用词不受词表影响 |

## 一、中文高频 AI 词

### 1.1 空泛动词 / 名词

| 词 | 常见语境 | 替代建议 | 何时保留 |
|---|---|---|---|
| 赋能 | 「技术赋能业务」「为 X 赋能」 | 直接说作用：帮助、支持、让 X 能…… | 有明确机制说明时（如「平台赋能小商家，提供物流与流量」）；工程/商业术语原文如此 |
| 助力 | 「助力企业发展」 | 帮助、推动、让……更顺利 | 作者自己的惯用词；真实效果有依据时 |
| 驱动 | 「数据驱动」「创新驱动」 | 依据、靠、由……决定 | 固定短语「数据驱动」在技术语境成立；「驱动」确有因果机制时 |
| 深耕 | 「深耕行业多年」 | 做了多年、长期专注 | 有具体年限/成果支撑时 |
| 聚焦 | 「聚焦三大问题」 | 围绕、重点讲、只谈 | 真实的范围限定（「本文聚焦 2023 年数据」） |
| 洞察 | 「获得深刻洞察」 | 发现、结论、看到的问题 | 指代具体的分析结果时 |
| 拆解 / 解构 | 「拆解这个案例」「解构现象」 | 分析、讲清楚 | 确实在分解结构时（「把流程拆成五步」） |
| 梳理 | 「梳理一下思路」 | 整理、捋清 | 有真实对象（「梳理近三年的合同」） |
| 彰显 / 展现 | 「彰显了团队的实力」 | 说明、体现、看得出 | 主语是作品/数据本身（「这张图展现了增长趋势」），且不是句尾拔高 |
| 夯实 / 筑牢 | 「夯实基础」 | 打好基础、巩固 | 政经正式语体原文如此，且不是堆叠 |
| 打造 / 构建 | 「打造生态」「构建体系」 | 做、建立、搭 | 有具体动作和对象时（「构建了三个服务模块」） |
| 落地 / 闭环 | 「方案落地」「形成闭环」 | 实施、完成、跑通 | 工程语境中「闭环反馈」「落地部署」等有具体含义的用法 |
| 开创 / 引领 | 「开创先河」「引领潮流」 | 第一次做了、带动 | 事实支持「第一次」或「领先」时 |
| 无缝 / 丝滑 | 「无缝衔接」「体验丝滑」 | 顺畅、衔接自然 | 技术语境「无缝迁移」指不中断，可保留；形容体验时删 |
| 至关重要 | 「至关重要的问题」 | 重要、关键 | 真有关键性判断时（「这一步至关重要，决定了……」，后文有依据） |
| 深入探讨 / 深入分析 | 「本文将深入探讨」 | 讨论、分析 | 后文确实展开细节时 |
| 显著提升 / 大幅优化 | 「显著提升效率」 | 提升、加快（附具体数字更好） | 有对比数据支撑时（「从 2 秒降到 0.3 秒」） |
| 充分 / 有效 / 深刻（装饰性状语） | 「充分地展示」「深刻地揭示」 | 删掉或落回事实 | 真正改变程度/范围/结果时（「充分」=「足够」，有依据） |

### 1.2 过渡与路标词

| 词 | 常见语境 | 替代建议 | 何时保留 |
|---|---|---|---|
| 值得注意的是 | 引出次要信息却郑重其事 | 直接写该信息 | 该信息确实反常、需要读者注意时（引语/原文如此不删） |
| 不难发现 | 替读者宣布结论 | 直接陈述结论 | 作者自己的口头禅（用户核实过的习惯） |
| 基于以上分析 | 总结段开头 | 直接写结论 | 有真实分析过程时，偶尔一次可保留 |
| 综上所述 / 总而言之 | 收尾段开头 | 直接写结论，或删掉 | 正式报告/公文语体，且结论有实质内容 |
| 与此同时 | 连接两件无时间关系的事 | 改用「另外」「而且」或删 | 确实表示同时发生 |
| 换句话说 / 换言之 | 重复已说内容 | 删掉重复，只留一遍 | 确实换了一种更易懂的说法时 |
| 事实上 / 实际上 | 引出并不反转的内容 | 删或直接陈述 | 真有转折/纠正误解时 |
| 更重要的是 / 更关键的是 | 句首拔高 | 直接写该点 | 该点确比前文重要且有依据 |
| 总体而言 / 整体来看 | 段首概括 | 直接给结论 | 有真实概括对象时 |
| 首先 / 其次 / 最后 | 提纲式列举 | 按内容自然衔接，保留真实顺序 | 步骤、流程有真实先后（「首先安装，其次配置」）；每段开头都有路标词才处理 |
| 随着……的发展 | 「随着技术不断发展」的万能背景 | 删掉或写具体变化 | 有真实趋势/因果（「随着文件数量增加，检索时间变长」） |
| 在这个……的时代 | 「在这个信息爆炸的时代」 | 删，直接进入主题 | 背景有独立信息时 |
| 值得深思 / 引人深思 | 句尾升华 | 删或写具体问题 | 作者明确表达观点时 |

### 1.3 客服腔（E22）

| 词 | 常见语境 | 替代建议 | 何时保留 |
|---|---|---|---|
| 好问题！ | 回答开头 | 直接回答 | 真实对话中确有互动需求 |
| 希望以上内容对你有帮助 | 结尾 | 删掉 | 客服回复、邮件落款（礼貌用语有用） |
| 如果您有任何问题，欢迎随时联系 | 结尾 | 删（独立文章）；留联系方式本身 | 客服、帮助文档、邮件 |
| 很高兴为您服务 | 开头/结尾 | 删 | 客服对话场景 |
| 让我来帮你 / 我来为你 | 开头 | 直接做 | 对话中确实在协助对方 |
| 请随时告诉我 / 有问题随时问我 | 结尾 | 删 | 对话、邮件 |
| 不用客气 / 不客气 | 应答 | 保留对话性 | 对话场景 |

### 1.4 套话收尾（F31、C13）

| 词 | 常见语境 | 替代建议 | 何时保留 |
|---|---|---|---|
| 让我们共同期待 | 结尾 | 删，停在实际内容上 | 演讲、活动文案等有意煽动场合 |
| 拭目以待 | 结尾 | 删或写具体计划 | 有真实待公布事项时 |
| 未来可期 / 未来可期！ | 结尾 | 删或写具体规划 | 有具体规划/证据时 |
| 期待更多可能 | 结尾 | 删 | 无 |
| 开启新篇章 / 迈向新征程 | 结尾 | 删，写具体事件 | 有真实里程碑时（「新版本上线」） |
| 相信 X 会越来越好 | 结尾 | 删或保留为明确的主观祝愿 | 作者明确表达祝愿（区别于陈述事实） |
| 标志着……的新时代 | 结尾 | 删「标志着」，保留事实 | 真实的历史性事件（第一次发布等） |

## 二、英文高频 AI 词

来源：stop-slop 与 humanizer §12（C12）。同样四列；弱单独项成簇才处理。

### 2.1 humanizer §12 词表

| 词 | 常见语境 | 替代建议 | 何时保留 |
|---|---|---|---|
| actually | 句首或句中强调 | 删；或用具体事实 | 真的在纠正误解时 |
| additionally | 段首连接 | 用 Also，或直接接下一句 | 正式文体的惯用连接 |
| align with | 「align with our goals」 | match, fit | 真实的对齐/协作语境（团队对齐目标） |
| bolstered | 「bolstered by」 | supported, helped | 有具体支撑证据时 |
| crucial | 强调重要性 | important, critical（后附原因） | 真有关键性判断且有依据时 |
| deep dive | 「a deep dive into X」 | look at, examine | 用户/行业惯用术语（技术文档「deep dive 章节」） |
| delve | 「delve into」 | examine, look into | 正式学术写作中有意使用 |
| enduring | 「an enduring legacy」 | lasting | 有真实时间跨度证据时 |
| enhance | 「enhance the experience」 | improve, make better | 有具体改进点（「enhance security with 2FA」） |
| garner | 「garner attention」 | get, attract | 有具体事实（「garnered 10k downloads」） |
| gate / gated | 「gated behind a paywall」 | 技术含义保留 | 技术用法（gate 流程、门控）一律保留 |
| highlight (动词) | 「highlight the importance」 | show, point out, stress | 确实在指出具体内容（「the chart highlights the spike」） |
| interplay | 「the interplay of X and Y」 | interaction, relationship | 有具体机制描述时 |
| intricate / intricacies | 「the intricacies of」 | details, complexity | 确实复杂且有细节展开时 |
| key (形容词) | 「key factors」 | main, central, 或具体名词 | 真的有主要/关键含义时 |
| landscape (抽象) | 「the tech landscape」 | field, market, situation | 具体指行业/市场格局时可保留 |
| meticulous / meticulously | 强调细致 | careful(ly) | 有具体细致行为支撑时 |
| pivotal | 「a pivotal moment」 | important, key（附依据） | 真实转折点且有依据时 |
| quietly | 「quietly building」 | 删或写具体动作 | 真的低调（无宣传）且有依据时 |
| robust (比喻) | 「robust solution」 | solid, strong | 技术含义（robust system 抗故障）保留 |
| showcase | 「showcase the talent」 | show, display | 展览/展示真实场景 |
| tapestry (抽象) | 「a tapestry of cultures」 | mix, range | 文学性写作中有意使用 |
| testament | 「a testament to」 | proof, sign | 有真实证据时 |
| underscore (动词) | 「underscore the importance」 | show, emphasize | 确实在强调具体事实时 |
| valuable | 「valuable insights」 | useful, 或具体价值 | 有具体用途时 |
| vibrant | 「vibrant community」 | lively, active | 有真实活跃证据时 |

### 2.2 stop-slop 词表

| 词 | 常见语境 | 替代建议 | 何时保留 |
|---|---|---|---|
| navigate (challenges) | 「navigate challenges」 | handle, address | 字面导航义（navigate the site） |
| unpack | 「let's unpack this」 | explain, examine | 正式学术/心理语境惯用 |
| lean into | 「lean into the trend」 | accept, embrace, adopt | 作者口语习惯 |

| double down | 「double down on X」 | commit to, increase | 金融/赌注字面义 |
| take a step back | 「take a step back and…」 | reconsider, look again | 字面义（退一步看全局） |

| circle back | 「circle back to this」 | return to, revisit | 商务口语真实场景 |
| on the same page | 「get on the same page」 | aligned, agreed | 口语对话 |
| really / just / literally | 句中强调 | 删 | 对话口语中自然出现 |
| genuinely / honestly / simply | 强调真诚/简单 | 删或换具体说法 | 作者真实态度表达 |
| actually | 强调 | 删 | 纠正误解时 |
| deeply / truly / fundamentally | 程度强调 | 删或附具体依据 | 真有深度/根本性时 |

| interestingly / importantly / crucially | 句首评价 | 删，直接写内容 | 后文确实有趣/重要时 |

| it's worth noting | 引出信息 | 直接写该信息 | 信息确实值得注意（引语保留） |
| at the end of the day | 总结 | 删 | 口语对话中自然 |
| when it comes to | 「when it comes to X」 | 直接以 X 开头 | 口语中自然 |
| in a world where | 万能背景 | 删，写具体情境 | 有真实情境时 |
| the reality is | 「the reality is that…」 | 直接陈述事实 | 真的在纠正误解时 |
