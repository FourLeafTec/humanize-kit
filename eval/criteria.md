# 编辑质量判据

判断顺序：**先查保真与任务，再评编辑收益**；正常文本先判「是否该改」。

## 评分（每维 1–10，总分 < 35/50 重写）

来源：stop-slop 5 维评分法，适配中文。

| 维度 | 问题 | 高分特征 |
|---|---|---|
| 直接性 | 陈述还是宣告？ | 直接说事，没有"接下来我将…"式宣告 |
| 节奏 | 有变化还是匀速？ | 长短句交错，有呼吸感 |
| 信任 | 尊重读者智力？ | 不解释读者已知的事，不替读者下结论 |
| 真实性 | 像人写的？ | 有具体细节与个人判断，无模板味 |
| 密度 | 有可删的吗？ | 无赘语、无重复铺垫 |

## 保真清单（硬性，逐项核对）

- [ ] 数字、日期、百分比：原样保留（格式可调，值不变）
- [ ] 否定范围：不丢"不/未/没有"，不改否定为肯定
- [ ] 条件："如果/只有/除非"保留
- [ ] 情态："可能/也许/觉得/计划/正在/已经"强度不变；可能≠确定，计划≠已经
- [ ] 归属：谁说的、谁做的，不擅自改归因（如把社区意见写成事实）
- [ ] 承诺与时间：交付时间、完成状态不变
- [ ] 术语与引语：专业术语、原文引用、书名号内容不动
- [ ] 无编造：不补原文没有的事实、数据、来源、身份、经历

## 任务核对

- [ ] 用户要求的范围执行（structural / bounded / in-place / 只标问题）
- [ ] 代码、命令、路径、链接目标、YAML、数据、标题锚点未动（文件模式）

## 误改判定（正常文本）

正常文本被改动且无编辑收益 → 记一次误改。目标：误改率 < 10%。
