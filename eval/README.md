# 评测方法论

目标：证明「改写后更像人」**且**「没改坏」。判据独立于 skill 文案本身。

## 两条硬门槛（参考 shuorenhua 发布要求）

1. **信息与任务硬失败 = 0**：数字、日期、条件、否定、情态、归属、承诺不得被改动或丢失；用户要求的任务（只标问题 / 只句内改 / 保留结构）必须执行。
2. **正常文本误改率 < 10%**：对正常人类语料，模型不得擅自改写；目标是不该动的都不动。

## 三类评测

| 类型 | 方法 | 工具/语料 |
|---|---|---|
| 保真硬检查（自动） | 原文/改稿成对，检查数字、日期、百分比丢失；痕迹词增减；节奏变化 | `scripts/score.py diff 原文 改稿`；任何数字/日期丢失 = 硬失败 |
| 盲测（人工或判官模型） | before/after 成对，判官盲选「更像人写的」；记录胜率 | 参考 humanizer 16/16 盲测、shuorenhua 123 条基准 |
| 误改率（正常文本） | 把正常人类文本喂给 skill，统计被改动的比例；目标 < 10% | `eval/cases/negative.md`；可扩展 HC3 人类侧语料 |

## 语料

- `eval/cases/positive.md`：待改善的 AI 味文本（改写任务输入）。
- `eval/cases/negative.md`：正常人类文本（误改率基线）。
- 可选扩展：[HC3 人类/机器问答对照语料](https://github.com/Hello-SimpleAI/chatgpt-comparison-detection)（HC3-Chinese / HC3-English）作语言学基线；`indicating_words_zh_chatgpt.txt` 特征词用于统计对照（特征词是统计信号，不是禁用词）。注：HC3 语料按上游声明为 **CC BY-SA 4.0**（更严格者优先），用作评测语料时注意分发约束。

## 判官判据

见 `criteria.md`：先查保真与任务完成，再评编辑收益；正常文本先判「是否该改」。评分 5 维 × 1–10，< 35/50 重写。

## 结果记录

每次评测在 `results/` 目录追加记录（尚未建立，首轮评测时创建），字段：版本 / 日期 / 模型 / 样本数 / 硬失败数 / 误改率 / 盲测胜率。单次、有限样例不能代表所有模型和文体；不能用字数下降或模型自评分证明效果。
